# AI Resume Customizer

**AI Resume Customizer** is an intelligent web application designed to generate and personalize professional resumes using AI.  
It enables users to tailor their resumes for specific job roles by analyzing job descriptions, extracting relevant keywords, and optimizing the content for ATS (Applicant Tracking Systems).

## 🧭 Overview

This project leverages **AI APIs (Gemini / OpenAI)** combined with **Supabase** as a backend to securely manage user data, templates, and API keys.  
The goal is to simplify and enhance the resume creation process for professionals and students seeking job-ready resumes with minimal effort.

---

## ✨ Key Features

- **AI-Powered Resume Generation** – Automatically customizes resumes based on input and job requirements.  
- **Keyword Optimization** – Matches job description keywords using Natural Language Processing (NLP).  
- **Multiple Templates** – Choose from modern, minimalist, or corporate-style templates.  
- **Supabase Integration** – Secure storage for user data and template configurations.  
- **Gemini API Integration** – Smart and context-aware resume content generation.  
- **Download Options** – Export resume in PDF format.  
- **Responsive UI** – Optimized for both desktop and mobile use.
